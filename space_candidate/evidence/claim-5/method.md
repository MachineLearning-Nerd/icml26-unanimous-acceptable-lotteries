# Method

Nested epsilon-quantized coordinate agents have thresholds `1/K, 2/K, ...`. A permutation that presents a chosen sequence of increasing record thresholds before the strongest threshold forces exactly the selected number `R` of LearnHyperplane calls. Identical accept-all agents are placed first so every record round incurs a full calibrated verification prefix.

The verifier executes exact Algorithm 2[`sigma`] with the same closed-form lexicographic `Select` validated for Claim 1. Sweeps vary operational `R`, `n`, `m`, and precision independently. Query counts are split into verification and elicitation components and checked against exact transcript formulas before comparison with the theorem envelope.

An order-independent invariant/counting certificate supplies the universal quantifier. A standalone checker reparses raw CSV and deliberately corrupts a count to prove fail-closed behavior.
