# Learning Unanimously Acceptable Lotteries via Queries

Source-faithful CPU reproduction for ICML 2026 paper `daiccpXZfU`,
*Learning Unanimously Acceptable Lotteries via Queries* (arXiv `2604.17505`).

The project will reproduce its five anchored exact query-complexity claims:
halfspace recovery, deterministic feasibility, randomized reweighting,
information-theoretic lower bounds, and learning-augmented ordering.
